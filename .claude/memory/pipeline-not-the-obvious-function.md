ב-05.09.2026 תוקן פענוח הזמנות מסעדה ב-`parseBookingEmail` — שם מדויק,
פרומפט מלא, השינוי נבנה ועבר. היא נקראת ממקום אחד: תיבת הדבקה ידנית.

הסריקה מתיבת הדואר, כלומר המסלול שהמשתמש באמת מריץ, עוברת ב-
`parseTravelDocument` → `buildExtractionPrompt`, ושם עמדה ההוראה
**ההפוכה**: "if the booking is for a restaurant table, set isBooking
to false". שלב שלם נכתב לענף מת.

**Why:** תיקון בפונקציה שאיש אינו קורא לה בונה, עובר בדיקות ואינו
משנה דבר על המסך — הכשל היחיד שנראה בדיוק כמו הצלחה.

**How to apply:** לפני תיקון בפרומפט, במפענח או בכל שירות — `grep` על
שם הפונקציה בכל `src`, ולרוץ אחורה מהמסך אל הקוראים. אם יש שתי
פונקציות שעושות אותו דבר, שתיהן צריכות את התיקון, או שאחת מהן מתה.
