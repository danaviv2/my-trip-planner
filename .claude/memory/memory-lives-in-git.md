תיקיית הזיכרון של Claude Code ממופתחת לפי **נתיב תיקיית העבודה**. כשהפרויקט
זז, נוצר מפתח חדש והזיכרון הקודם פשוט לא נטען — בלי שגיאה ובלי סימן. זה קרה
פעמיים: ב-18.8.2026 כשהתיקייה נעלמה, וב-23.8.2026 כשהסשן נפתח בטעות ב-
`my-trip-planner-backup-FINAL-WORKING` (תיקייה כמעט ריקה ששמה מטעה).

**הפתרון שנבנה ב-23.8.2026:** קבצי הזיכרון חיים ב-`.claude/memory/` בתוך
הריפו ונשמרים ב-git; התיקייה תחת `~/.claude/projects/<key>/memory` היא
**קישור סימבולי** אליהם. לכן הזיכרון עולה ל-GitHub, שורד מעבר תיקייה, ושורד
מחשב חדש. `.gitignore` מחריג אותם במפורש (`.claude/*` + `!.claude/memory/`).

**מה לעשות אם הזיכרון נראה ריק בפתיחת שיחה:** לבדוק אם הקישור קיים —
`ls -ld ~/.claude/projects/*my-trip-planner/memory`. אם נוצרה שם תיקייה
אמיתית במקום קישור, ליצור אותו מחדש אל `.claude/memory` שבריפו.
